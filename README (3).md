# Memowrite for Visual Studio Code

Adds the **Memowrite** language to VS Code:

* Syntax colors for `.mw` files (commands, shapes, built-in words, text with `{interpolation}`)
* The Memowrite icon on `.mw` files
* Snippets: type `window`, `task`, `repeat`, `model`, `game` ... and press Tab
* **Run** button (top right) or `Ctrl+F5` runs your program in the terminal
* **Check** (`F7`) finds mistakes and underlines the line - also runs every time you save
* Auto indent after `if`, `repeat`, `make task` ... and outdent on `end`

Memowrite must be installed (the Memowrite installer puts `memowrite` on your PATH).
